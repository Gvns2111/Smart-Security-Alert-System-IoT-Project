# Smart Security Alert System (IoT Simulation)

## 📌 Overview
A smart home security alert system simulated using Cisco Packet Tracer. It integrates PIR sensors, webcam modules, Raspberry Pi logic, alarms, and automated rules to detect intrusions and notify the homeowner.

## 🚀 Features
- Motion detection using PIR  
- Image capture using webcam  
- Raspberry Pi logic processing  
- Automated alarm triggering  
- Instant notifications  

## 🧠 Concepts Used
- IoT device integration  
- Smart home automation  
- Sensor-based alerting  
- Simulation using Packet Tracer
